# ELDEN RING 快適攻略ガイド（ネタバレなし情報まとめ）

『ELDEN RING（エルデンリング）』の探索・戦闘・キャラクター育成を快適に進めるための特化型まとめWebアプリケーションです。

ストーリーのネタバレやボス進行フローを一切排除し、**「序盤から死なずにサクサク進めるための実用情報」**（基本操作、おすすめ素性と装備、最強ビルド、聖杯瓶強化、地図断片、ルーン稼ぎ）に特化しています。

## 📤 GitHubへのアップロード & GitHub Pages 公開手順

本プロジェクトは GitHub Pages へのデプロイに最適化されています（`base: './'` 設定済み、自動デプロイ用 GitHub Actions ワークフロー同梱）。

### 1. リポジトリをGitHubにプッシュ

GitHub上で新しい空のリポジトリ（例: `elden-ring-guide`）を作成し、以下のコマンドを実行します：

```bash
git remote add origin https://github.com/あなたのユーザー名/elden-ring-guide.git
git branch -M main
git push -u origin main
```

### 2. GitHub Pages を有効化する

1. GitHub のリポジトリページを開き、**「Settings」**タブをクリック。
2. 左メニューの**「Pages」**を選択。
3. **「Build and deployment」** の **「Source」** を **『GitHub Actions』** に変更します。
4. 数分後、自動的にビルド＆デプロイが完了し、公開URL（`https://あなたのユーザー名.github.io/elden-ring-guide/`）が表示されます！
