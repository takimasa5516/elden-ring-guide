# ELDEN RING 快適攻略ガイド（ネタバレなし情報まとめ）

『ELDEN RING（エルデンリング）』の探索・戦闘・キャラクター育成を快適に進めるための特化型まとめWebアプリケーションです。

ストーリーのネタバレやボス進行フローを一切排除し、**「序盤から死なずにサクサク進めるための実用情報」**（進行度別ロードマップ、地域別マップ、神遺灰＆神タリスマン、基本操作、おすすめ素性と装備、最強ビルド、聖杯瓶強化、地図断片、ルーン稼ぎ）に特化しています。

---

## 🌟 主な機能と収録コンテンツ

1. **進行度別サバイバル指針（序盤・中盤・終盤）**【NEW!】
   - **序盤 (Lv.1〜40)**: 生存力爆上げ＆探索基盤の確立。南下して啜り泣きの半島巡り、生命力30極振り、大竜グレイオール約10万ルーン。
   - **中盤 (Lv.40〜80)**: ビルド特化＆最強武器・鈴玉の解放。レナラ撃破でステ振り直し解放、ヴァレーイベントでモーグウィン早期アクセス、祈祷「火の癒しよ」で腐敗対策。
   - **終盤 (Lv.80〜150)**: ビルド完成＆最強遺灰・決戦兵器の配備。写し身の雫＆ティシーを+10強化、竜印の大盾タリスマン、しろがね坂で時給1,000万ルーン。
2. **地域別インタラクティブマップ ＆ 重要スポット**【NEW!】
   - リムグレイブ・啜り泣き、湖のリエーニエ、ケイリッド・竜塚、アルター高原・ゲルミア火山、地下世界の5大地域。
   - 教会（聖杯の雫）、坑道（鍛石）、小黄金樹（霊薬雫）、廃墟（重要アイテム）のマップピン配置。
   - ピンをタップすると入手アイテムと詳細解説を表示。
   - 地域ごとの地図断片場所、おすすめ探索ルート、危険エネミー注意報。
3. **神遺灰 ＆ 神タリスマン ＆ 攻略知識**【NEW!】
   - **神遺灰5選**: 霊クラゲ、民兵、首なし騎士ルーテル、写し身の雫、黒き刃ティシー。
   - **調霊師ローデリカの解放手順**: 遺灰を+10まで最大強化して不死身のタンクにする必須手順。
   - **神タリスマン**: ラダゴンの爛れ刻印（全ステ+20ブースト）、緑亀、黄金樹の恩寵、竜印大盾、アレキサンダーの破片。
   - **お守り袋の増やし方**: タリスマン装備枠を最大4枠まで増やす3つの手順。
   - **ステータス振り直し（生まれ直し）**: レナラ＆戦闘なしで拾える「雫の幼生」安全マップ。
   - **初心者必読の罠解除**: フィアの最大HP5%減少デバフ解除法、転送罠脱出ルール、亀ミリエルへの書物集約。
4. **基本操作 ＆ 探索・戦闘の極意**
   - PlayStation (PS5/PS4) / Xbox / PC（キーボード＆マウス）のボタン操作対応表（ワンタップ切り替え）
   - ガードカウンター、両手持ち、ジャンプ攻撃、ダッシュ・ローリングなどの重要テクニック
5. **おすすめ素性 ＆ 序盤装備**
   - おすすめ素性（放浪騎士・侍・星見・密使・勇者・預言者）のステータス比較と育成パス
   - ボス討伐不要で拾える強力な武器・触媒・盾（猟犬の長牙、打刀、グレートソード、隕石の杖、岩石弾、名刀月隠、真鍮の盾など）
6. **おすすめ最強ビルド ＆ ステ振り**
   - 4大ビルド徹底解説：純筋力（脳筋重装）、技量・神秘（出血）、純魔術（知力砲台）、信仰戦士（聖騎士・冒涜の聖剣）
   - レベル別ステータス目標表（Lv.50 / Lv.100 / Lv.150）
7. **強化アイテム ＆ 地図断片の確保場所**
   - 聖杯の雫（各地の教会巡りで回復量最大化）、黄金の種子、地図断片、鍛石掘りの鈴玉。
8. **ルーン稼ぎ完全ガイド**
   - ルーン1.56倍重複（金のスカラベ ＋ 鳥脚の黄金漬け）、大竜グレイオール、モーグウィン王朝カラス落とし＆しろがね坂。
9. **探索チェックリスト（トラッカー）**
   - 全36箇所の重要アイテム回収進捗を記録（LocalStorage自動保存）。

## 🚀 ローカルでの開発・実行手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド（型チェック + バンドル）
npm run build
```
